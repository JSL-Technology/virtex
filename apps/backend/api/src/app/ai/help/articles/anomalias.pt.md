## O que é

Análise › Anomalias reúne o que o sistema encontrou de incomum em vendas, compras, estoque, caixa e segurança: faturas de fornecedor duplicadas, vendas abaixo do custo, descontos fora do normal, ajustes de estoque grandes, pagamentos duplicados, compras faturadas que não coincidem com o pedido ou recebido, mudanças de preço, alterações depois de emitir e atividade fora do horário, entre outros.

## Como se trabalha

Cada achado mostra a evidência com os seus números. Você pode pedir uma explicação em linguagem simples (consome um crédito de IA). Marque cada um como útil ou como falso positivo: essa decisão ensina ao sistema quais detectores importam para a sua empresa. Um achado grave novo também chega como aviso no sino.

## Importante

Uma anomalia é uma pista para uma pessoa revisar, não uma acusação. Muitos achados têm uma explicação legítima.
